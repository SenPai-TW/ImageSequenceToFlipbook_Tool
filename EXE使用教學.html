五步完成輸出

開啟 EXE

雙擊 FlipbookGenerator.exe。第一次冷啟動會將必要元件解壓到 Windows 暫存目錄，可能需要多等幾秒。

選擇來源

選擇「序列圖片」、「圖片資料夾」或「影片 MP4／MOV」，再按「瀏覽…」；也可以直接拖入一張圖片、一個圖片資料夾或一部影片。

設定 Flipbook

輸入欄數、列數與單格尺寸，再選擇通道模式和畫面適配。右側會自動更新容量、完整尺寸與低解析預覽。

選擇輸出位置

在右側「輸出位置」按「瀏覽…」，指定 PNG 檔名與儲存資料夾。

產生 Flipbook

按「產生 Flipbook 網格圖」，等待進度完成。完成後可按「開啟輸出資料夾」查看結果。

3

選對來源模式

推薦：編號序列

序列圖片

只要選序列中的任一張，例如 smoke_003.png。程式會尋找同資料夾、相同命名規則的圖片，依最後一段數字自然排序。

整個資料夾

圖片資料夾

讀取資料夾第一層中的支援圖片，不會搜尋子資料夾。適合檔名規則不同、但都要放入同一張 Flipbook 的素材。

單一影片

影片 MP4／MOV

選擇一部 MP4 或 MOV。程式會分析解析度、FPS、影格數與長度，再依指定時間範圍平均抽取畫面。

拖放一次只能放入一個來源。 多個項目、空資料夾或不支援格式不會取代目前設定。
4

設定網格與影像

設定用途實用建議
欄數（Cols）每一橫列放幾格。遊戲或材質常用 4、8、16。
列數（Rows）由上到下共有幾列。總容量＝欄數 × 列數。
單格尺寸每格影像的正方形邊長，單位為 pixel。常用 128、256、512、1024。
通道模式決定透明度與 RGB 如何輸出。透明特效通常選 RGBA（透明）。
補齊空格來源少於容量時，以最後一格填滿。不勾選則保留透明／黑色空格。
完整輸出尺寸：寬度＝欄數 × 單格尺寸；高度＝列數 × 單格尺寸。
例如 8 × 8、單格 256 px，輸出就是 2048 × 2048 px。

三種畫面適配

它們只改變每一格如何放入正方形，不會改變欄列順序。

置中裁切

保持比例並填滿正方形；畫面邊緣可能被裁掉，不會變形。

拉伸成正方形

完整填滿格子，但非正方形來源會被拉伸，比例可能變形。

預設／最不破壞原圖

延伸空白畫布至正方形

完整保留畫面和比例；RGBA 補透明區域，不透明通道補黑底。

5

影片模式要注意什麼？

等待影片分析完成

選取 MP4／MOV 後，先等待畫面顯示解析度、FPS、總影格數與影片長度，再開始生成。

設定開始與結束秒數

可以輸入小數秒，例如開始 1.5、結束 5.0。開始時間必須小於結束時間；結束留空代表影片結尾。

程式會平均取樣

最多抽取「欄數 × 列數」個不重複影格，涵蓋完整指定範圍，不是只取影片開頭；音訊不會輸出。

影片影格比網格容量多時會平均抽取；影格較少時保留空格，只有勾選「用最後一格補齊剩餘空格」才會重複最後一格。
6

預覽、生成與檢查

先看右側低解析預覽

預覽用來快速確認順序、格數、裁切與透明區域，不會寫入磁碟。正式輸出仍以完整解析度重新處理。

指定 PNG 輸出位置

選擇你有寫入權限的資料夾並輸入檔名。若已存在同名檔案，請先確認是否要覆蓋。

等待進度完成

生成期間不要關閉程式。狀態顯示完成後，再使用「開啟輸出資料夾」檢查 PNG。

7

常見問題

第一次開啟比較慢，正常嗎？

正常。單一 EXE 會先把內含的 Python、Pillow、FFmpeg 與介面元件解壓到 Windows 暫存目錄，冷啟動通常比之後開啟慢。

Windows SmartScreen 顯示警告怎麼辦？

自行建置的 EXE 沒有程式碼簽章時可能出現警告。請先確認檔案確實來自你信任的專案或 GitHub Repository；來源無誤時才選「其他資訊／更多資訊」後執行，不要略過來路不明檔案的警告。

為什麼序列順序不對？

建議使用具有連續編號的檔名，例如 frame_001.png、frame_002.png。序列圖片模式會以檔名最後一段數字自然排序；若要混合不同命名規則，改用圖片資料夾模式並先整理檔名。

為什麼有圖片沒有輸出？

來源數量若超過網格容量，圖片模式會忽略超出容量的尾端圖片；請增加欄數或列數。影片模式則會在指定時間範圍內平均抽取到目前容量。

透明背景變成黑色？

請選擇「RGBA（透明）」通道模式。其他不透明通道會移除 Alpha；使用延伸畫布時，不透明模式的空白區域會補純黑色。

EXR 可以直接使用嗎？

目前 EXE 主要支援 PNG、JPEG、TIFF 及 MP4／MOV。一般 Pillow 環境不保證可讀 EXR，建議先轉成保留需求通道的 PNG 或 TIFF。

輸出檔很大或處理很慢？

完整尺寸會隨欄數、列數與單格尺寸快速增加。例如 16 × 16、每格 1024 px 會輸出 16384 × 16384 px。先降低單格尺寸或網格數量，再確認記憶體是否足夠。
